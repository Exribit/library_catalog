# Library Catalog API

REST API сервис для управления библиотечным каталогом. Проект построен на базе **FastAPI** с использованием строгой многослойной архитектуры (Layered Architecture), паттернов Repository и Dependency Injection. 

Сервис не только обеспечивает стандартные CRUD-операции, но и автоматически обогащает данные о книгах (обложки, темы, издательства) через интеграцию с внешним API **Open Library**.

## Технологический стек

* **Язык:** Python 3.12+
* **Фреймворк:** FastAPI
* **База данных:** PostgreSQL 16
* **ORM & Миграции:** SQLAlchemy 2.0 (Async), Alembic, asyncpg
* **Валидация данных:** Pydantic V2, Pydantic-Settings
* **HTTP-клиент:** HTTPX (асинхронные запросы)
* **Пакетный менеджер:** Poetry

## Архитектура

Приложение разделено на 4 независимых слоя:

1. **API Layer (`api/`)**: Тонкие роутеры. Отвечают за прием HTTP-запросов, валидацию Pydantic-схем и сериализацию ответов.
2. **Domain Layer (`domain/`)**: Бизнес-логика приложения, правила валидации данных, мапперы и оркестрация внешних вызовов.
3. **Data Layer (`data/`)**: Слой доступа к данным. Реализует паттерн Repository поверх асинхронных сессий SQLAlchemy 2.0.
4. **External Layer (`external/`)**: Интеграция с внешними HTTP API (Open Library) с обработкой таймаутов и повторными попытками запросов.

## Быстрый старт (Ubuntu / Linux)

Предварительные требования
###
Убедитесь, что в системе установлены:
* Python 3.12+
* Poetry
* Docker & Docker Compose
###


### Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone <url-вашего-репозитория>
   cd library_catalog
   ```

2. **Настройка переменных окружения:**
   ```bash
   cp .env.example .env
   ```
   *(При необходимости скорректируйте параметры подключения в созданном файле `.env`)*

3. **Запуск PostgreSQL в контейнере:**
   ```bash
   docker-compose up -d postgres
   ```

4. **Установка зависимостей проекта:**
   ```bash
   poetry install
   ```

5. **Применение миграций базы данных:**
   ```bash
   poetry run alembic upgrade head
   ```

6. **Запуск сервера разработки:**
   ```bash
   poetry run python -m src.library_catalog.main
   ```

После старта API доступно по адресу: `http://127.0.0.1:8000`

### Основные эндпоинты

* `GET /api/v1/health` — проверка доступности сервиса и соединения с PostgreSQL.
* `POST /api/v1/books/` — добавление книги с автоматическим обогащением метаданных из Open Library.
* `GET /api/v1/books/` — фильтрация и пагинация каталога (по названию, автору, жанру, году и статусу).
* `GET /api/v1/books/{book_id}` — получение подробной карточки книги.
* `PATCH /api/v1/books/{book_id}` — частичное обновление записи.
* `DELETE /api/v1/books/{book_id}` — удаление книги из каталога.
